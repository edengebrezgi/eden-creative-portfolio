# Eden Gebrezgi — Creative Production Portfolio

A static portfolio website designed for animation-production applications.

## Publish free with GitHub Pages

1. Create a free GitHub account if you do not already have one.
2. Create a new **public** repository named `portfolio` (or `eden-animation-portfolio`).
3. Upload **everything inside this folder** to the repository root. `index.html` must be at the top level.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)` folder, then save.
7. GitHub will show the public URL after deployment. It will look similar to:
   `https://YOUR-USERNAME.github.io/portfolio/`

No paid plan, trial, domain, or credit card is required for this setup.

## Before sharing

- Test every video and PDF link.
- Test on mobile.
- Confirm the email, LinkedIn, and DeviantArt links.
- You can replace any file inside `assets/` later without rebuilding the whole site.
